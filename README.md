# Diffusion-Policy 复现练习
# OpenArm 单臂 Push-T 任务环境

## 1. 仿真平台与版本

| 项目 | 说明 |
|---|---|
| 仿真器 | MuJoCo 3.x（固定 minor 版本，如 **3.1.4**） |
| Python API | `mujoco` 官方绑定 |
| 环境封装 | 自定义 `OpenArmPushTEnv` 类（基于 Python 原生封装） |

## 2. 任务定义

| 项目 | 说明 |
|---|---|
| 任务目标 | 控制 OpenArm 右臂（7-DoF），通过夹爪推动 T 形块，使其位置与朝向对齐绿色目标区域 |
| 终止条件 | 成功判定达成，或达到最大步数（如 **300 步**） |
| 成功判据 1 | T 形块中心 `(x, y)` 与目标中心误差 **< 0.03 m** |
| 成功判据 2 | T 形块偏航角（Yaw）与目标偏航角误差 **< 0.15 rad** |

## 3. 观测定义（与 A1 一致）

| 项目 | 说明 |
|---|---|
| 观测模态 | 本体感受（Proprioception）+ 物体状态（特权信息）；无视觉输入（如后续加入视觉，使用 `camera_wrist_right`） |
| 维度 | **23 维（float32）** |
| 组成 1：T 形块状态 | 位置 (3) + 四元数 (4) + 线/角速度 (6) = **13 维** |
| 组成 2：末端状态 | 右臂末端控制点 `right_ee_control_point` 笛卡尔位置 (3) = **3 维** |
| 组成 3：目标状态 | 目标区域中心位置 (3) + 四元数 (4) = **7 维** |
| 频率 | 与控制频率一致（**20 Hz**） |
| 归一化 | 暂无额外归一化（直接输出世界坐标系下的绝对坐标/速度） |
| 历史帧 | 单帧（DP 算法内部自行处理历史序列） |

## 4. 动作定义（与 A1 一致）

| 项目 | 说明 |
|---|---|
| 动作空间类型 | 末端笛卡尔绝对位置（Task Space Position） |
| 维度 | **2 维（平面 x, y）** |
| 范围与限幅 | `x ∈ [0.10, 0.50]`，`y ∈ [-0.30, 0.05]`（单位：m），超出范围会被 `np.clip` 截断 |
| 语义 | 动作输入代表期望的右臂末端 `(x, y)` 坐标，高度 `z` 固定为 **0.06 m**（推块高度） |
| 底层控制 | 内部通过阻尼最小二乘（DLS）逆运动学（IK）将 `(x, y)` 解算为右臂 7 个关节的角度，并下发给底层 position 伺服器 |
| 控制频率 | **20 Hz**（对应仿真步长 0.002 s，`frame_skip = 25`） |

## 5. 随机初态

| 项目 | 说明 |
|---|---|
| T 形块初始位置 | 以 `(0.30, -0.12)` 为均值，在 **±0.05 m** 范围内均匀采样 `(x, y)` |
| T 形块初始朝向 | 在 `[-π, π]` 范围内均匀采样（Yaw） |
| 目标区域初始位置 | 相对 T 形块初始位置，在工作空间 `[0.25, 0.45] × [-0.25, -0.05]` 内随机采样 |
| 右臂初始关节角 | 保持固定的初始姿态（通过 IK 算好的 `right_home`） |
| 随机种子策略 | 由外部传入 `seed`，确保数据采集与评测时的随机初态可复现 |

## 6. 仿真步长 / 控制步长

| 项目 | 说明 |
|---|---|
| 物理仿真步长（`timestep`） | **0.002 s**（500 Hz，Euler 积分器） |
| 控制频率 | **20 Hz**（控制周期 0.05 s） |
| Frame Skip | **25**（即每次 `env.step()` 调用内部执行 25 次物理步进） |
| 对 DP 的影响 | DP 的预测动作序列（Action Horizon）需按 20 Hz 的频率进行截断与执行 |
| DP 建议 `action_horizon` | **4 ~ 8**（对应未来 0.2 s ~ 0.4 s 的动作） |
| DP 建议 `obs_horizon` | **2**（观测两帧以计算速度/趋势） |
